# 🧮 Python Calculator Web Application

A simple and user-friendly calculator web application built using **Python, Flask, HTML, and CSS**. It performs basic arithmetic operations through a clean web interface.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Input validation for invalid numbers
- Division-by-zero error handling
- Simple and responsive user interface
- Real-time result display after submitting the form

## 🛠️ Technologies Used

- **Python** — Application logic
- **Flask** — Web framework
- **HTML5** — Page structure
- **CSS3** — User interface styling
- **Git and GitHub** — Version control and project hosting

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Shalini5254/Python_Calculator.git
```

### 2. Navigate to the project folder

```bash
cd Python_Calculator
```

### 3. Install Flask

```bash
python -m pip install flask
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

Visit:

```text
http://127.0.0.1:5000
```
